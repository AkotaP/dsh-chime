# 经验球组件

经验球是组合包内默认关闭的可选组件，行 id 为 `chime-xp`。原通知组件的事件、配置和开关保持独立。

## 启用与设置

1. 在 DSH 插件页打开 dsh-chime，开启“经验球音效”组件（行标识 `chime-xp`）。
2. 打开该组件行的配置页面，填写音频的 HTTP(S) 链接或本地绝对路径。目录浏览沿用原插件的本地音源访问能力。
3. 点击单声试听或 10 秒节奏试听，确认音源可播放，再开启“启用自动经验音”。浏览器可能需要首次点击解锁音频。

插件不附带、不下载 MC 音频。使用原始、未经变调的短音源更接近原版；录制过的拾取音可能已经变调。选择长音频会增加尾音重叠，不适合密集播放。

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 随机连响时长下限 | 1 秒 | 0.1–30 秒 |
| 随机连响时长上限 | 3 秒 | 0.1–30 秒；不小于下限 |
| 经验球产生频率 | 6 个/秒 | 0.1–10 个/秒 |
| 音量 | 10% | 0–100% |
| 窗口失焦后继续播放 | 关闭 | 开启/关闭 |
| 自动经验音 | 关闭 | 开启/关闭 |

音源和数字输入在失焦或按 Enter 后保存；其他控件即时保存。设置保存在当前浏览器的 localStorage，键为 `dsh.chime.xp.config.v1`，与原通知配置隔离。

## 触发规则

- 只监听当前正在查看的会话，不额外订阅子代理或其他后台会话。
- 任意工具的新 `tool/result` 到达后触发，成功和失败结果均计入。不按工具名称筛选；不是每个 token 或工具开始时触发。
- 每次从时长上下限之间均匀抽取连响时长，按配置频率发声。新触发将结束时间更新为“现有结束时间”和“当前时间加新抽取时长”的较大值，不叠加多个播放循环或积压待播经验球。
- 频率控制每声的起始间隔，最高每 100 毫秒一声。尾音允许自然重叠，最多同时保留 32 个声部，超过时释放最旧声部。
- 等待审批/回答、Agent 停止或完成、切换会话、关闭功能、清空音源、卸载组件时停止。默认窗口失焦或隐藏也停止；重新聚焦不补播。
- 历史加载、向上翻页、刷新和重连产生的基线替换不触发。定时器被后台节流时不补齐漏掉的声音。
- 关闭通知组件不影响经验球。经验球的音源路由、浏览器入口和配置由自身组件持有。

工具结果仅表示工具调用结束，不表示任务成功、代码正确或真实完成了多少工作。连续触发可能使连响持续超过单次时长上限；该上限约束每次抽样，不是整个 Agent 回合的总时长。

## MC 风格音频规则

每声使用同一音源，以两个独立的均匀随机数计算播放速率：

```js
playbackRate = 0.9 + (Math.random() - Math.random()) * 0.35;
```

音高倍率约为 0.55–1.25，中心为 0.9，呈三角分布；不量化成音阶、不强制避开重复、不添加上行旋律。播放速率同时改变音高和时长，HTMLAudio 后备路径关闭音高保持。

查证依据：[客户端实现镜像（1.20.3-pre1）](https://raw.githubusercontent.com/mahtomedi/minecraft/main/src/main/java/net/minecraft/client/multiplayer/ClientPacketListener.java)、[经验球拾取冷却](https://raw.githubusercontent.com/mahtomedi/minecraft/main/src/main/java/net/minecraft/world/entity/ExperienceOrb.java)、[单一样本声音清单（1.9.1）](https://raw.githubusercontent.com/InventivetalentDev/minecraft-assets/1.9.1/assets/minecraft/sounds.json)。这是对已查证 Java 版发声规则的复现，不声称所有 MC 版本相同。Agent 工具到虚拟经验球的映射是插件自定义规则。

音量默认增益为 0.1，但浏览器混音与游戏混音不同，且自选音源响度不同，不能保证与游戏具有相同的主观响度。

## 打包与兼容

最低 DSH 版本为 0.2.1-rc.2。子组件位于 `components/xp`，以具名工作区依赖 `dsh-chime-xp` 加入主包，并通过 `bundledDependencies` 随主包分发，无需单独发布或下载。开发时先执行 `pnpm install` 建立工作区依赖链接。Loader 使用包名而非文件路径加载组件；导出的 `locale/zh.json` 与 `locale/en.json` 提供标题及描述，避免将文件 URL 当成名称显示。

从旧路径入口升级时保持 `chime-xp` 行 ID 和配置存储键不变。更新后可在插件页关闭再开启 dsh-chime 触发重组，然后重新打开组件配置页；不需要重启 DSH 或重新设置音源。

`node build.mjs` 同时生成原通知与经验球两组 host/client 产物。仓库构建不会修改 DSH profile，也不会重启服务；当前已安装的 link 版本是否已重新组合，需要在插件页另行确认。
